# Shiori

A personal PDF library and reader. Add a PDF and Shiori turns it into a clean, reflowed book — chapters, images and original page numbers kept — with automatic place saving, six-colour highlights, notes, read-aloud and a knowledge view of everything you've kept.

Everything is stored on your device (IndexedDB). Nothing is uploaded.

Install on iPhone: open the site in Safari → Share → Add to Home Screen.
